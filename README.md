# Ultra Sol!!!

GPT-5.6 Solの登場を、Ultra Soulとの言葉遊びで勝手に祝う非公式パロディLPです。

## Live

https://ultra-sol-lp.maigo999.workers.dev

## Features

- 巨大タイポグラフィとCSS太陽フレア
- スクロール・ポインター連動演出
- MAX / ULTRAモード切替
- モバイル固定ナビゲーション
- `prefers-reduced-motion`、キーボード、ARIA対応
- SVG原稿から生成するOGP・favicon・アプリアイコン
- canonical、OG/Twitter、JSON-LD、sitemap、robots対応
- Cloudflare Workers Static Assets配信

## Stack

- Vite 8
- Vanilla TypeScript
- CSS
- Vitest + jsdom
- Cloudflare Workers Static Assets

## Development

```bash
npm install
npm run generate:assets
npm run dev
```

## Verification

```bash
npm run test:run
npm run typecheck
npm run build
```

## Deployment

```bash
npm run deploy
```
