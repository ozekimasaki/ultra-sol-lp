# Ultra Sol!!! LP デザイン仕様

## 目的

GPT-5.6 Sol の登場を、ライブ会場の高揚感と「Ultra Soul / Ultra Sol」の言葉遊びで祝う非公式パロディLPを制作する。閲覧者が数秒でネタを理解し、スクロールするほど Sol の特徴と勢いを感じられる体験を目指す。

## 表現方針

- OpenAI公式ページのコピーではなく、黒を基調に太陽の白熱色、ライム、青紫を差し色にした独自のライブポスター表現とする。
- ファーストビューに「ULTRA SOL!!!」を最大級のタイポグラフィで配置し、「止まるな。考えろ。進め！」を行動メッセージにする。
- CSSの太陽フレア、グリッド、粒子、走査線、等化器で熱量を出す。写真や第三者ロゴは使用しない。
- 情報は GPT-5.6 Sol の公式発表に基づき、`max` 推論エフォート、`ultra` モード、最大毎秒750トークンの提供予定を短いカードで紹介する。

## ページ構成

1. 固定ナビゲーション：ブランド表記、章リンク、公式情報へのリンク
2. ヒーロー：巨大タイトル、太陽オブジェクト、宣言文、2つのCTA
3. キネティック帯：「DON'T STOP / THINK DEEPER / GO ULTRA」
4. 能力セクション：`max`、`ultra`、`750 tok/s` の3カード
5. インタラクティブセクション：MAXとULTRAを切り替えてコピーと視覚強度を変更
6. モデルファミリー：Sol / Terra / Luna の役割を簡潔に提示
7. 最終CTA：OpenAI公式記事とYouTube Musicへ誘導
8. フッター：非公式パロディであり、OpenAIおよびB'zと無関係である旨を明記

## インタラクション

- ポインター位置に追従する光と、スクロール進捗バーを表示する。
- IntersectionObserverで要素を順次表示する。
- MAX / ULTRA切替はボタン、キーボード、支援技術から操作でき、`aria-pressed`とライブ領域を更新する。
- `prefers-reduced-motion`では移動・点滅・追従演出を停止し、情報を失わない静的表示にする。

## 技術設計

- Vite 8.x、Vanilla TypeScript、CSS。Reactやアニメーションライブラリは使わず、初期表示を軽量に保つ。
- HTML生成、状態ロジック、起動処理、スタイルを分離する。
- Vitest + jsdomで主要コンテンツ、外部リンク、モード切替、進捗計算をテストする。
- 375pxから大型デスクトップまで対応し、セマンティックHTML、可視フォーカス、十分なコントラストを担保する。

## 完了条件

- `npm test`、`npm run typecheck`、`npm run build`が成功する。
- 実ブラウザで主要セクション、外部リンク、モード切替、レスポンシブ表示、コンソールエラーなしを確認する。
- 自動再生、無断埋め込み、第三者ロゴの模倣を行わない。
